# Zone Diet Application

크로스핏 존다 8주 프로그램용 팀 관리 앱입니다. 회원 20명, 관리자 1명, 기본 5개 팀으로 시작합니다.

## 실행

Node.js 24 LTS를 사용합니다.

```sh
npm ci
npm start
```

로컬 주소는 http://localhost:3000 입니다. 로컬 개발 데이터는 `.data/`에 저장됩니다. 기존 단일 사진 기록도 그대로 사용할 수 있습니다.

## 주요 기능

- 관리자 팀 편성 및 식단·조장·미션운동·SNS·기타 역할 지정
- 회원별 로그인과 개인 체중·운동 기록
- 아침·점심·저녁마다 사진 최대 6장, 추가·제거 및 확대 갤러리
- 같은 팀의 식단 사진 확인
- 현재 식단 담당자만 날짜별 사진 모음을 전체 회원에게 공유
- 공유 시점의 사진 보존, 명시적인 재공유로 갱신
- 로그인·팀·역할 검사, 변경 버전 검사, 충돌 시 덮어쓰기 방지

## Vercel 배포

`vercel.json`은 정적 화면과 Node.js API를 함께 배포합니다. 서버리스 실행 환경에서 로컬 파일 시스템에 기록을 저장하지 않습니다.

1. Vercel 프로젝트에 **Private Vercel Blob** 저장소를 연결합니다.
2. `BLOB_READ_WRITE_TOKEN`과 `INITIAL_ACCOUNT_PASSWORDS`를 Production 환경변수에 설정합니다. `.env.example`에서 키 형식을 확인할 수 있습니다.
3. `INITIAL_ACCOUNT_PASSWORDS`는 `admin`, `member01`부터 `member20`까지 8자 이상의 비밀번호를 담은 JSON입니다. 데모에서는 간단한 비밀번호를 사용할 수 있으며, 실제 운영 시에는 계정별로 강한 비밀번호를 사용하세요. 비밀번호를 저장소에 커밋하지 마세요.
4. 배포하면 빈 저장소에 가상의 회원 20명과 관리자 계정이 초기화됩니다. 초기화 이후 환경변수 변경만으로 기존 비밀번호가 변경되지는 않습니다.

온라인 사진·회원정보·세션은 비공개 Blob에 저장합니다. 요청마다 최신 상태를 읽고 ETag 조건부 쓰기로 동시 변경을 확인합니다. 사진은 앱의 로그인과 공개 범위를 확인한 뒤에만 제공합니다. 로컬 `.data/`나 계정 안내 파일은 배포 및 Git 대상에서 제외됩니다.

전체 상태를 하나의 문서로 저장하므로 동시에 저장하면 재시도가 필요할 수 있습니다. 현재 20명 규모의 시범 운영을 위한 구성입니다. 본격 운영 전 회원 가입·비밀번호 변경/복구, 데이터 보존·삭제 정책을 추가해야 합니다.
